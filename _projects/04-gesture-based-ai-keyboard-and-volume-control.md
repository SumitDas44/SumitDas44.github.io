## Overview

Contactless interface using MediaPipe hand tracking and OpenCV; thumb-index pinch gestures simulate keyboard input while finger proximity controls system volume.

## Key details

Implemented keyboard interaction with pynput and volume control through Windows Audio API.

**Technologies:** Python, OpenCV, MediaPipe, pynput.
